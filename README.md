# Teranga Shop

App pour ceux qui vendent en ligne (TikTok, Instagram, Facebook, WhatsApp) — Seck Apps.

- `index.html` : app du vendeur (compte, démo) et espace livreur (`?b=CODE&livreur`)
- `boutique.html` : pages des clients — boutique (`?b=CODE`), live (`&live`), suivi (`&s=…&k=…`), avis (`&a=…&k=…`)
- Données : Supabase « seck.apps.sn », tables `shop_*`
